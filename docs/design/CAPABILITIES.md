# What the public routes do today

[SPEC.md](../../SPEC.md) states the model this project is committed to and [MODEL.md](MODEL.md) derives
it. Both are requirements. This page is the description: one row for each requirement the shipped code does not yet
meet, what it does instead, and the test that pins that behaviour today. Change a row in the commit that changes the
behaviour; delete a row when the code meets the requirement.

The public routes are `sv_pgs.fit_model.fit` (the `sv-pgs fit` command, over a dosage store),
`sv_pgs.small_n.fit_small_n` and `sv_pgs.pooled_fit.fit_pooled_small_n` (the dense cis-window routes that
`benchmarks/svpgs_method.py` and `benchmarks/svpgs_small_n.py` enter), `sv_pgs.artifact.predict` (the `sv-pgs score`
command) and `sv_pgs.workspace_pipeline.run_pipeline` (the `sv-pgs workspace-run` command).

| The requirement | What the code does today | The test that pins it |
|---|---|---|
| A continuous annotation enters the prior "as a smooth function with learned smoothness"; every variant's prior variance depends on its SV context. | Every prior builder passes a zero-width annotation design and no annotation groups (`stage2_wiring.py`, `small_n.small_n_prior`, `pooled_fit.pooled_prior`), and `prior_design` is imported by no fitting route. A variant's prior therefore depends on its class and its log r² alone. bench-real's `fit_expression_no_annotations` arm removes no annotation column; it merges the classes into one. | no test |
| Prior hyperparameters are "pooled hierarchically across classes and traits". | Classes share one prior in every route. Traits do not: `stage2_wiring.fit_models` fits each model on its own rows and merges the certificates afterwards. `pooled_fit` pools one prior across the genes of a single trait. | `tests/test_pooled_fit.py::test_several_genes_fit_one_certified_prior` (across genes, one trait) |
| "A logistic likelihood for diseases" (README, MODEL.md). | Quantitative traits only. `stage2_wiring.fit_models` and `small_n.fit_small_n` raise `NotImplementedError` for any other trait type, and `logistic_ep` is imported by no fitting route. | no test |
| "Any grid used to compute with it is only a quadrature rule. It is refined until results change by less than a derived tolerance." | The variant routes build one lattice from the single-variant likelihoods at the covariate-only noise (`derived_lattice`, `stage0_lattice`) and never refine it against the fitted density. `halved_lattice` is called only by `phenotype_measurement`, and `tail_mass` by no fitting route, although `derived_lattice`'s own docstring promises that refinement. | the primitives only (`tests/test_scale_mixture_ep.py`); no test of a variant fit's independence of its grid |
| "The inference is empirical Bayes: hyperparameters are type-II maximum likelihood under an expectation-propagation approximation." | Two inferences sit behind `fit_small_n(inference=...)`: EP by default, and mean-field coordinate ascent (`mean_field.MeanFieldFixedPoints`), which is the arm the bench-real gene runs use. The store route is EP only. Which one survives is the open measurement in HANDOFF.md. | `tests/test_small_n.py::test_the_small_n_fit_certifies_and_scores`, `tests/test_mean_field.py::test_the_mean_field_fit_scores` |
| "A fit is accepted only with its convergence certificate." | A fit that cannot certify is returned with its certificate terms and its `certified` flag false, not refused. The mean-field interior state cannot certify at all (HANDOFF.md Next 0/0a). | `tests/test_mean_field.py::test_the_mean_field_fit_certifies` (strict xfail) |
| A dosage store goes through `fit` to a saved artifact and scores. | `tests/test_fit_model.py` drives `fit` with a stand-in driver, so it checks the wiring, not the engine. The one test that runs the real engine through `fit_model.fit` is a strict expected failure: the full-data driver refuses its synthetic start. | `tests/test_stage2_wiring.py::test_fit_runs_the_engine_and_the_saved_model_scores_the_store` (strict xfail) |
| "A stored dosage is a measurement of the true genotype, with a truth-calibrated reliability r². GATK-SV short-read calls are a second measurement ... and the two are fused." | r² reaches the fit as the prior's log-variance offset, from the caller or from the store's `quality` column (`stage2_wiring.store_log_reliability`). `measurement_model` and `sv_fusion` are imported by no fitting route; they build stores and the workspace's measurement step. bench-real passes no offsets at all. | `tests/test_fit_model.py::test_the_driver_gets_the_records_log_reliabilities` |
| `sv-pgs workspace-run` fits the workspace's cohort. | It stops before its first step. `workspace_bindings()` requires `fit_model.fit` to accept `measurement` and `target_variance`, which it does not, and raises `RuntimeError`. The pipeline's tests bind doubles that do accept them. | no test |
